# SFX Files

Place `.ogg` files here. AudioManager loads them by name at startup; missing files are silently skipped.

| Filename | Trigger |
|---|---|
| `mirror_place.ogg` | Mirror placed on grid |
| `mirror_remove.ogg` | Mirror removed from grid |
| `mirror_rotate.ogg` | Mirror rotated (left-click on existing) |
| `beam_solved.ogg` | Star beam reaches the target |
| `level_complete.ogg` | Level complete panel appears |
| `fragment_collect.ogg` | Memory fragment collected |
| `mode_switch.ogg` | Tab — design ↔ explore transition |
| `ui_click.ogg` | Generic UI button press |

Recommended format: mono `.ogg` Vorbis, 44 100 Hz, –14 LUFS.
